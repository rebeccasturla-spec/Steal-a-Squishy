# Steal a Squishy 🧸

Original Roblox/Luau collection-and-stealing game foundation.

## Current foundation
- Six player bases
- Squishy rarity/economy configuration
- Server-authoritative purchase and income systems
- Base locking
- Stealing with RemoteEvents
- Persistent player data
- Starter UI hooks

See STUDIO_SETUP.md for Roblox Studio setup.
